#TMDB CLI Tool

#How to run
1. Clone the repository anywhere in your PC
2. Open terminal inside the directory
3. Run this command -> mvn package (to create the target folder and the jar file) Note: make sure to have maven downloaded in your PC
4. Run the jar file like this -> java -jar target\com-tmdb-jerme.jar genre your-command

#Commands
1. help    - helps you viewing all the commands and their formats
2. np      - shows the currently playing movies
3. popular - shows all the popular movies of all time
4. upc     - shows the upcoming moviess
5. top     - shows the current top movies
